Executive Summary

Problem Statement

Manual trading XAUUSD, Forex, and Crypto requires constant screen time, emotional discipline, and precise execution timing — all of which degrade under fatigue and market stress. Existing retail platforms lack integrated technical analysis automation with SMC (Smart Money Concepts) and flexible strategy execution.

Proposed Solution

Build an automated algo-trading system that: (1) ingests real-time market data from MT5, (2) runs comprehensive technical analysis (MACD, EMA, Fibonacci, SMC, Volume Profile, candlestick patterns), (3) evaluates configurable YAML-based strategies, and (4) executes trades automatically via MT5 with strict risk management. A React dashboard provides real-time monitoring and a Claude AI co-pilot provides market analysis on demand.

Scope

In Scope

  • Market data ingestion from MetaTrader5 (XAUUSD, EURUSD, GBPUSD, BTCUSD, ETHUSD)
  • Technical indicators: MACD, EMA (20/50/200), Fibonacci Retracements, Fibonacci Time Zones, Fibonacci Cycles
  • Advanced analysis: Volume Profile (VPVR), SMC (Order Blocks, FVG, BOS/ChoCH, Liquidity), Support/Resistance, Demand/Supply zones, Wick Fill, SL Sweep
  • Candlestick pattern recognition (Hammer, Engulfing, Doji, Morning/Evening Star, Pin Bar)
  • YAML-based strategy configuration and evaluation engine
  • Auto-execution via MT5 Python library
  • Money management: Fixed Lot, Fixed Fractional, Kelly Criterion
  • Execution strategies: Grid, Martingale, Hedging, News Trading, HFT Scalping
  • Risk management: SL/TP, Trailing Stop, Daily Loss Cap, Max Drawdown, Position Limits
  • TradingView Pine Script alert → webhook integration
  • React dashboard: live chart with indicator overlays, positions, trade log, P&L
  • Claude AI co-pilot: chat-based market analysis and strategy building
  • Economic calendar integration for news trading
  • TimescaleDB for OHLCV + trade history
  • Redis as real-time message bus

Out of Scope

  • Multi-user / team collaboration features
  • Mobile app (web dashboard only)
  • Broker integration other than MetaTrader5
  • Options, futures, or DeFi trading
  • Social trading / copy trading
  • Payment processing or subscription management
  • Backtesting engine (future phase)
  • Cloud deployment (Windows-only constraint from MT5)

Assumptions

  • MetaTrader5 is installed on the Windows machine running the system
  • A funded MT5 demo account is available for testing
  • TradingView account with webhook capability (Pro or above for real-time)
  • Anthropic API key provisioned
  • Internet connection stable during market hours
  • Single user — no concurrent session management required

AS-IS State

Current Process

Trader monitors MT5 and TradingView charts manually. When indicators align (e.g. EMA crossover + MACD bullish), trader manually places orders in MT5 with manually calculated lot size and SL/TP. Analysis is performed visually — no automated indicator computation. No automated risk cap enforcement.

User Stories

US-001 — Auto-execute trade on EMA crossover

As a trader, I want the system to automatically open a buy order when EMA 20 crosses above EMA 50 with MACD bullish confluence, so that I don't miss EMA crossover entries during off-hours.

Given the strategy ema_macd_xauusd is active on XAUUSD H1
When EMA20 crosses above EMA50 AND MACD histogram turns positive on candle close
Then system places a Buy market order with configured lot size, SL, and TP

US-002 — Halt trading on daily loss cap

As a trader, I want the system to stop all new auto-trades when today's realized loss exceeds $200, so that I never blow my account in a single bad day.

Given MAX_DAILY_LOSS_USD is set to 200
When total realized losses for the calendar day reach $200
Then system rejects all new order intents and logs a daily cap breach alert

US-003 — Ask Claude about current market setup

As a trader, I want to ask the Claude AI co-pilot "What does the XAUUSD H1 setup look like?" and get a summary of current indicators, so I can make a faster manual decision.

Given the user types a market analysis question in the co-pilot chat
When Claude receives the question with current OHLCV + indicator context
Then Claude returns a structured analysis in <30s including SMC zones, EMA position, MACD trend

US-004 — TradingView alert triggers trade

As a trader, I want TradingView Pine Script alerts to trigger trades automatically, so I can use TradingView's charting tools as signal source.

Given a Pine Script alert fires and POSTs to /webhook/tradingview
When the webhook payload contains valid symbol, action, and strategy_id
Then system maps the alert to the named strategy and executes if risk checks pass

US-005 — Grid trading on BTCUSD

As a trader, I want to run a grid trading strategy on BTCUSD that automatically opens buy/sell orders at fixed price intervals, so I can profit from range-bound markets passively.

Given a grid strategy config with spacing=500 USD, lot=0.01, levels=5
When BTCUSD price moves into a grid level
Then system opens the corresponding grid order and updates the grid state

Glossary

TermDefinition
MT5MetaTrader 5 — broker trading terminal and execution platform
OHLCVOpen, High, Low, Close, Volume — standard candle data format
MACDMoving Average Convergence Divergence — momentum indicator
EMAExponential Moving Average — trend-following indicator weighted toward recent prices
FibonacciFibonacci retracement/extension levels derived from the Fibonacci sequence ratios
SMCSmart Money Concepts — price action analysis methodology based on institutional order flow
Order BlockSMC: Last bearish/bullish candle before a strong move — acts as support/resistance
FVGFair Value Gap — price imbalance zone (gap between candle wicks) that price tends to revisit
BOSBreak of Structure — price breaks a prior swing high/low, confirming trend direction
ChoCHChange of Character — first BOS in the opposite direction, signals potential trend reversal
SSL/BSLSell-Side Liquidity / Buy-Side Liquidity — pools of stop-loss orders below/above key levels
VPVRVolume Profile Visible Range — volume distribution by price level over a visible chart range
SL/TPStop Loss / Take Profit — price levels at which a position is automatically closed
MartingaleStrategy that doubles (or multiplies) lot size after each loss to recover previous losses
Grid TradingStrategy placing buy/sell orders at fixed price intervals above and below current price
HedgingOpening an opposing position on the same symbol to lock in a loss or manage risk
Kelly CriterionMathematical formula for optimal position sizing based on win rate and reward/risk ratio
HFTHigh Frequency Trading — algorithmic trading at very high speed and frequency
Pine ScriptTradingView's scripting language for creating custom indicators and alerts
TimescaleDBPostgreSQL extension optimized for time-series data storage and queries
FastAPIModern Python web framework for building async APIs with automatic OpenAPI documentation
