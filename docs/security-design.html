Auth Middleware (FastAPI dependency)

from fastapi import Security, HTTPException
from fastapi.security import HTTPBearer, HTTPAuthorizationCredentials
import jwt

security = HTTPBearer()

async def verify_token(
    credentials: HTTPAuthorizationCredentials = Security(security)
) -> dict:
    try:
        payload = jwt.decode(
            credentials.credentials,
            settings.API_SECRET_KEY,
            algorithms=["HS256"]
        )
        return payload
    except jwt.ExpiredSignatureError:
        raise HTTPException(401, "Token expired")
    except jwt.InvalidTokenError:
        raise HTTPException(401, "Invalid token")

Webhook Security

HMAC-SHA256 Signature Verification

TradingView Pine Script alerts include a shared secret in the payload. The webhook handler verifies the signature before processing any trade signal.

import hmac
import hashlib

def verify_webhook_signature(
    body: bytes,
    signature_header: str,
    secret: str
) -> bool:
    expected = hmac.new(
        secret.encode(),
        body,
        hashlib.sha256
    ).hexdigest()
    received = signature_header.split("=")[-1]  # "sha256=abc123"
    return hmac.compare_digest(expected, received)  # constant-time compare

# FastAPI handler
@router.post("/webhook/tradingview")
async def tradingview_webhook(
    request: Request,
    x_signature: str = Header(alias="X-Signature")
):
    body = await request.body()
    if not verify_webhook_signature(body, x_signature, settings.TRADINGVIEW_WEBHOOK_SECRET):
        raise HTTPException(401, "Invalid webhook signature")
    payload = WebhookPayload.model_validate_json(body)
    ...

Secret Management

Never commit secrets to version control. All sensitive values loaded exclusively from environment variables via pydantic-settings.

Secret Generation

# Generate strong secrets (PowerShell)
[System.Convert]::ToBase64String([System.Security.Cryptography.RandomNumberGenerator]::GetBytes(32))

# Python
python -c "import secrets; print(secrets.token_urlsafe(32))"

What is NEVER logged or returned

  • MT5_PASSWORD, MT5_LOGIN — never in any log line or API response
  • ANTHROPIC_API_KEY — never returned; masked in health check
  • API_SECRET_KEY — never returned; used only for JWT ops
  • POSTGRES_PASSWORD — never in application logs

Input Validation

All request bodies use Pydantic v2 strict validation. Field types, lengths, and allowed values enforced at deserialization. Webhook payload validated before any processing.

class WebhookPayload(BaseModel):
    model_config = ConfigDict(strict=True)
    symbol:      str = Field(min_length=3, max_length=20, pattern=r'^[A-Z0-9]+$')
    action:      Literal["BUY", "SELL", "CLOSE_ALL"]
    price:       float = Field(gt=0)
    strategy_id: str = Field(min_length=1, max_length=100)
    timeframe:   str = Field(pattern=r'^(M1|M5|M15|M30|H1|H4|D1|W1)$')

Circuit Breaker — MT5 Connection

class MT5CircuitBreaker:
    def __init__(self, failure_threshold=3, recovery_timeout=60):
        self.failures = 0
        self.state = "CLOSED"  # CLOSED=normal, OPEN=halt
        self.last_failure = None

    async def call(self, fn, *args, **kwargs):
        if self.state == "OPEN":
            if (time.time() - self.last_failure) > self.recovery_timeout:
                self.state = "HALF_OPEN"  # try once
            else:
                raise CircuitBreakerOpen("MT5 disconnected — trading halted")
        try:
            result = await fn(*args, **kwargs)
            self.failures = 0
            self.state = "CLOSED"
            return result
        except MT5ConnectionError:
            self.failures += 1
            self.last_failure = time.time()
            if self.failures >= self.failure_threshold:
                self.state = "OPEN"
                logger.critical("MT5 circuit breaker OPEN — all new orders halted")
            raise

What is Always Logged

  • Every OrderIntent (with trade_id, symbol, lot, strategy) — before MT5 send
  • Every MT5 order result (ticket, fill price, or error)
  • Every risk manager rejection (reason: daily cap / position limit / MT5 disconnected)
  • Every JWT auth event (success + failure)
  • Every webhook received (including rejected signatures)
  • MT5 circuit breaker state changes (OPEN / CLOSED / HALF_OPEN)

What is Never Logged

  • MT5 password, login ID, server address
  • ANTHROPIC_API_KEY or any other API key
  • JWT secret or token payload contents
  • POSTGRES_PASSWORD
