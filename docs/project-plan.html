Overview

AITrading development follows the devstarter SDLC gate model. Feature development occurs in Gate 4, split into 3 phases. All issues tracked on GitHub Issues with milestones per phase. Solo developer (clickzika).

PhaseFocusEst. DurationMilestone
Gate 3Foundation: scaffold + Docker + GitHub Issues1 weekv0.1-foundation
Phase 1Analysis engine + MT5 feed + OHLCV storage3-4 weeksv0.2-analysis
Phase 2Strategy engine + auto-execution + risk manager4-5 weeksv0.3-autotrading
Phase 3Dashboard + WebSocket + Claude AI co-pilot3-4 weeksv1.0-dashboard
