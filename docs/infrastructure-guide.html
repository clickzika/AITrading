Architecture Map

All services run on a single Windows 11 machine. Docker Desktop handles TimescaleDB and Redis. Python backend and React frontend run as Windows native processes.

ServiceRuntimePortNotes
TimescaleDBDocker container5432PostgreSQL 15 + TimescaleDB extension
RedisDocker container6379Pub/sub message bus + cache. No persistence needed.
FastAPI backendWindows Python (venv)8000Must run native — MetaTrader5 lib is Windows-only
React dashboardVite dev server5173Or nginx on port 80 for production build
MetaTrader5Windows appN/AMust be running and logged in

Docker Compose

# docker-compose.yml
version: '3.9'
services:
  timescaledb:
    image: timescale/timescaledb:latest-pg15
    container_name: aitrading_db
    environment:
      POSTGRES_DB: aitrading
      POSTGRES_USER: aitrading
      POSTGRES_PASSWORD: ${POSTGRES_PASSWORD}
    ports:
      - "5432:5432"
    volumes:
      - timescaledb_data:/var/lib/postgresql/data
    restart: unless-stopped
    healthcheck:
      test: ["CMD-SHELL", "pg_isready -U aitrading"]
      interval: 5s
      timeout: 5s
      retries: 5

  redis:
    image: redis:7-alpine
    container_name: aitrading_redis
    ports:
      - "6379:6379"
    command: redis-server --maxmemory 256mb --maxmemory-policy allkeys-lru
    restart: unless-stopped
    healthcheck:
      test: ["CMD", "redis-cli", "ping"]
      interval: 5s
      timeout: 3s
      retries: 3

volumes:
  timescaledb_data:

Docker Commands

# Start DB + Redis
docker compose up -d

# Check health
docker compose ps

# View logs
docker compose logs -f timescaledb
docker compose logs -f redis

# Stop
docker compose down

# Stop + remove data (DESTRUCTIVE)
docker compose down -v

Backend Setup

Initial Setup

# Clone repo
git clone https://github.com/clickzika/AITrading.git
cd AITrading

# Create Python venv
python -m venv .venv
.venv\Scripts\activate   # PowerShell: .venv\Scripts\Activate.ps1

# Install dependencies
pip install -r backend/requirements.txt

# Install TA-Lib (Windows — use pre-compiled wheel)
pip install TA_Lib-0.4.28-cp311-cp311-win_amd64.whl

# Copy .env and fill in values
copy .env.example .env
notepad .env

Environment Variables (.env)

# === Required ===
ANTHROPIC_API_KEY=sk-ant-...
MT5_LOGIN=12345678
MT5_PASSWORD=your_mt5_password
MT5_SERVER=YourBroker-Demo
MT5_PATH=C:\Program Files\MetaTrader 5\terminal64.exe

DATABASE_URL=postgresql+asyncpg://aitrading:YOUR_PW@localhost:5432/aitrading
POSTGRES_PASSWORD=YOUR_PW
REDIS_URL=redis://localhost:6379/0

API_SECRET_KEY=generate-with-python-secrets-module-min-32-chars
TRADINGVIEW_WEBHOOK_SECRET=another-random-secret-min-16-chars

# === Trading Safety ===
TRADING_MODE=demo              # demo | live — MUST be "live" for real trading
MAX_DAILY_LOSS_USD=200
MAX_OPEN_POSITIONS=5
MAX_LOT_SIZE=1.0
DEFAULT_LOT_SIZE=0.01

# === Optional ===
CORS_ORIGINS=["http://localhost:5173"]
JWT_EXPIRY_HOURS=24
LOG_LEVEL=INFO

Run Migrations

cd backend
alembic upgrade head

Start Backend

cd backend
uvicorn main:app --host 0.0.0.0 --port 8000 --reload

# Production (no reload)
uvicorn main:app --host 0.0.0.0 --port 8000 --workers 1

Verify Backend

# Health check
curl http://localhost:8000/health

# Expected response
{
  "status": "healthy",
  "mt5": "connected",
  "db": "connected",
  "redis": "connected",
  "trading_mode": "demo"

MT5 Setup Checklist

1
Install MetaTrader5
Download from broker website. Login with demo account credentials.
2
Enable Algorithmic Trading
MT5 → Tools → Options → Expert Advisors → ✓ Allow algorithmic trading
3
Set MT5_PATH in .env
Full path to terminal64.exe, e.g. C:\Program Files\MetaTrader 5\terminal64.exe
4
Keep MT5 running
MetaTrader5 Python lib connects to the running terminal. MT5 must be open before starting backend.
5
Verify connection
Check health endpoint: curl localhost:8000/health → "mt5": "connected"
6
Test with demo account
Confirm TRADING_MODE=demo in .env. Run a strategy eval — watch demo account for test trade.

Start / Stop Procedures

Full System Start (order matters)

# 1. Start Docker services (DB + Redis)
docker compose up -d

# 2. Open MetaTrader5 and log in

# 3. Activate Python venv and start backend
cd AITrading\backend
.venv\Scripts\Activate.ps1
uvicorn main:app --port 8000

# 4. Start frontend
cd ..\frontend
npm run dev

# 5. Open browser
# http://localhost:5173

Graceful Shutdown

# Stop backend (Ctrl+C in terminal)
# Stop frontend (Ctrl+C in terminal)
# Stop Docker
docker compose down
# Close MetaTrader5 (optional — positions remain in broker)
